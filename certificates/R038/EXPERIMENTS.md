# Recorded experiments / 已记录实验

The R038 theorem run uses parent side `99974999999/100000000000` and the pinned base measure. / R038 定理运行使用父边长 `99974999999/100000000000` 与锁定的基础测度。

The exact base-measure chunks are `[0,500)`, `[500,1500)`, `[1500,2500)`, `[2500,3500)`, and `[3500,4391)`. / 基础测度的精确分块为 `[0,500)`、`[500,1500)`、`[1500,2500)`、`[2500,3500)` 与 `[3500,4391)`。

Their merged histogram is `2860×1000000030`, `1428×1000000032`, and `103×1000000035`, with `27918671` centre slabs and zero escapes. / 合并后的直方图为 `2860×1000000030`、`1428×1000000032` 与 `103×1000000035`，共有 `27918671` 个中心条带且零逃逸。

The separate augmented-orbit control uses the same five ranges and gives `2860×1000000032`, `1428×1000000034`, and `103×1000000037`, with `27967621` centre slabs and zero escapes. / 独立的增广轨道对照使用相同五个区间，并得到 `2860×1000000032`、`1428×1000000034` 与 `103×1000000037`，共有 `27967621` 个中心条带且零逃逸。

The augmented surplus is larger, but the base measure already passes the new endpoint, so the extra surplus is not claimed as the cause of this numerical improvement. / 增广后的余量更大，但基础测度已经通过新端点，因此不把额外余量宣称为本次数值提升的原因。
