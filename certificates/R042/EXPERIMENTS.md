# Public experiment record / 公开实验记录

R042 starts from the pinned Kled v1.0.0 baseline at parent side `99853/100000` and lower bound `461300/99853`. / R042 从锁定的 Kled v1.0.0 基线出发，其父边长为 `99853/100000`，下界为 `461300/99853`。

The accepted public delta changes the parent side to `24963/25000`, increases threshold-orbit-22 prototype weight from `12202158` to `12402158`, and retargets the core side in 7,848 of the 7,853 catalogue rows while preserving the interval partition and orientations. / 已接受的公开差异把父边长改为 `24963/25000`，将阈值轨道 22 的原型权重从 `12202158` 提高到 `12402158`，并在保持区间划分与方向不变的情况下重新定向 7,853 个目录行中的 7,848 个内核边长。

The D4 expansion of that prototype-weight change increases the global budget by `800000` integer units. / 该原型权重变化经 D4 展开后使全局预算增加 `800000` 个整数单位。

The complete Python replay and the reconstructed BigInt replay both pass all 7,853 rows with identical minimum histograms and global minimum `1000002306`. / 完整 Python 复演与重建 BigInt 复演都通过全部 7,853 行，并得到完全相同的最低值直方图与全局最低值 `1000002306`。

Exploratory failed candidates and search-frontier diagnostics are intentionally excluded from this public result package because they are not theorem inputs. / 探索性失败候选与搜索前沿诊断被有意排除在本公开成果包之外，因为它们不是定理输入。
