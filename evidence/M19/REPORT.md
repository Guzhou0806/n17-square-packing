# M17/M19：加密网的失败见证与非均匀网下界

本轮研究将“完整加密失败”与“部分已认证方向仍可利用”分开记录。

M17固定原子、权重和探针边长，预声明尝试旧181方向之间的180个中点。三个预检方向通过后，按冻结顺序在第17个计算方向、旧区间k=14发现精确捕获质量197153/200000，低于必要统一门槛423327/425000；按协议立即停止。独立逐原子计数确认此合法探针只捕获125个原子，因此该固定全361方向证书失败。这不否定其他原子、权重、探针尺寸或下界方法。

M19随后明确另立，确定性使用M17全部16个已通过方向，加上旧181方向形成197节点非均匀网；没有追加搜索，也没有把M17改写成成功。第二套完整覆盖算法对全部17个已计算方向逐一得到完全相同的最小质量，确认16个通过值与1个失败值。

非均匀网的最大相邻半角隙在旧区间[14h,15h]取得，其正切从h降到

`D=621321000000/270300253166143`。

沿用已认证的严格包含和有理缩放族，可得到普通全局下界

`s(17) ≥ 45900*sqrt(73062612901466039895961496449)/2702984545455608711`

`≈4.5900426689726359505272262851896`。

它较M14提高约0.00001167910610349934。适用于任意位置和旋转，不是固定分支下界；仍不声称端点不可装填、严格大于该值、全局最优或世界纪录。
