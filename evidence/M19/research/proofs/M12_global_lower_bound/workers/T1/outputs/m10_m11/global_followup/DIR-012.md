# DIR-012｜T-019 固定比例 dilation 候选静态审查

日期：2026-09-17  
范围：单一锁定 T-019 证书、固定 `λ=1000001/1000000`；不执行 verifier、不优化原子、不改变方向网、不影响 M10/M11。

## 结论

候选转移在数学结构上成立，且比最初给出的平方不等式更容易接入现有 verifier：对 T-019 的实际最大 half-gap tangent `D=h=207107/90000000`，不仅

`(λB(1+h))² < 1+h²`，

而且现有 `certificate.py` 使用的更强粗条件

`λB(1+D) < 1`

也严格成立。因此，只要重新独立重放原证书的 181 个有限方向覆盖，按 `λ` 同比放大容器、探针和全部原子坐标、保持权重与方向网不变，就得到可由同一五条件框架检查的候选边长

`S' = λ(459/100) = 459000459/100000000 = 4.59000459`。

但本轮没有执行有限覆盖，故这仍是**条件性候选**，不能登记为新的全局下界。

## 1. 与真实 source 逻辑的核对

锁定的 `sqpack/fractional/certificate.py`（本地静态副本 `s16-certificate.py`，SHA-256 `174ae7c3f6081684afd2cbaa6459211bf05971755df753359064a540a84ab1ba`）明确列出五项：

1. 原子多重集关于容器 `D4` 对称；
2. 总质量 `<n`；
3. half-tangent 网从 `0` 到达 `tan(π/8)`，结合 D4 覆盖全部方向；
4. `B(1+D)<1`，其中
   `D=max (t_{k+1}-t_k)/(1+t_kt_{k+1})`
   是相邻方向**半角间距的正切**；
5. 每个 net direction 的每个可达中心胞元覆盖质量至少 1。

对 T-019，`t_k=kh`，分母 `1+t_kt_{k+1}≥1`，故最大值在首间隔取得，`D=h`。源码的几何桥接正是：任意单位方块选择最近 net direction，角差 `d` 满足 `tan d≤D`；同中心 B-square 的横向支撑为 `B(cos d+sin d)`，由 Condition 4 严格小于 1，所以缩小方块严格处于单位方块内部并消除接触边双计数。该逻辑与候选一致。

## 2. 固定 λ 的精确余量

令

- `B=9977/10000`；
- `h=D=207107/90000000`；
- `λ=1000001/1000000`。

则：

- `B'=λB=9977009977/10000000000`；
- `S'=λL=459000459/100000000`；
- 现有粗 Condition 4 的精确余量
  `1-λB(1+D)=2793464693461/900000000000000000>0`
  （约 `3.10385×10^-6`）；
- 候选给出的 sharpened 平方余量
  `1+D²-(λB(1+D))²`
  `=1035284398853867376315700426831/90000000000000000000000000000000000>0`
  （约 `1.15032×10^-5`）。

因此本固定 λ 不需要修改 source theorem 或调用 sharpened endpoint lemma；原始较强 Condition 4 已足够。

共同缩放保持其余条件：D4 关于缩放后容器仍成立；质量和方向网不变；任意 `B'`-square placement 经除以 λ 与原容器中的 B-square placement 一一对应，并捕获相同索引原子，故 Condition 5 的最小质量理论上仍为 `200009/200000`。这一等变性必须由独立 checker 对实际缩放映射和原覆盖结果绑定，不能只凭文字继承。

## 4. 独立有限覆盖算法审查

T0 提议的固定方向 sweep 理论架构有效：

1. 把原子旋转到 probe 的 `(u,v)` 轴。一个原子被中心 `(u,v)` 的闭 B-square 捕获，当且仅当中心落在 `[u_p-B/2,u_p+B/2]×[v_p-B/2,v_p+B/2]`，即中心空间的轴对齐闭矩形。
2. probe 可行中心域是 `[r,S-r]^2` 在 `(u,v)` 坐标中的旋转像，其中 `r=B(cosθ+sinθ)/2`；它是有内点的凸四边形。把其顶点 u 坐标加入事件后，每个开 u-strip 内，上下 v 边界均为线性函数。
3. 每个 strip 内活跃原子矩形集合不变，覆盖关于 v 是区间 range-add 的阶梯函数。strip 与可行四边形的 v 投影中出现某个阶梯区间，当且仅当存在对应可行中心；因此可用坐标压缩后的 range-add/range-min 树查询最小覆盖。
4. 所有矩形边界采用闭捕获。事件线或可行域边界上的点可由内部开胞元逼近，而落在捕获边界的原子只会在边界处增加质量，不会制造比相邻开胞元更低的值。实现仍须对“仅在端点相交”的空开区间作精确判定，以避免把不存在的胞元计入 minimum。
5. 每方向有 `O(N)` 个 u/v 事件；标准区间树给出 `O(N logN)` 更新/查询。该数据权重的共同分母为 `200000`，整数权重总和 `3386616`，可安全置于 int64；几何比较仍须用 `Fraction`，不能转 float。

这是一种标准 exact sweep/segment-tree 实现方案。锁定 `certificate.py` 注释描述其 source `sweep.py` 使用 `(2N+2)^2` dense int64 event grid，因此 T0 方案可作为积累架构独立的 checker；但未读取 `sweep.py` 全文，不据此作算法新颖性判断。

## 5. 最小完整重放接口

### A. Source-faithful 最小接口

1. 锁定原字节：T-019 `certificate.json`、`replay.py`、`sqpack/fractional/certificate.py`、`model.py`、`sweep.py`、`workers.py` 及实际 import closure/环境锁文件。
2. `replay.load()` 精确构造 source `Certificate`。
3. `certificate.verify(source, workers=1)` 重放 Conditions 1–5，并检查总质量 `423327/25000`、worst `200009/200000`、方向数 181 和声明一致。
4. 构造 scaled Certificate：`outer_side`、`square_side`、每个 atom 的 x/y 乘 λ；weight、half_tangents、n、D4 不变。
5. 对 scaled object 再调用同一 `verify(...,workers=1)`。因为粗 Condition 4 已通过，不需要修改 verifier；检查五项全部通过且 minimum 与 source 相同。
6. 输出绑定 source/scaled canonical bytes、代码/环境哈希、逐条件数值和 wall/CPU/RSS。source 注释估计本例每 worker dense grid `(2·1184+2)^2·8=44,935,200` bytes（约 42.85 MiB）；`workers=1` 是最小、确定性较强的预算入口，运行时间目前 unknown。

### B. 独立最小接口

1. 独立解析同一 JSON，检查非负权重、坐标范围、D4、多重站点唯一性、质量、网格单调性和 exact arc condition `t_last²+2t_last-1≥0`。
2. 对 181 个方向运行上述 Fraction + integer segment-tree sweep，输出每方向 minimum 和全局 worst；拒绝任何 float/tolerance。
3. 独立验证 fixed-λ 缩放、`λB(1+D)<1`、`S'=4.59000459` 和覆盖等变 bijection；scaled sweep 可作为正对照，但数学上 source sweep + bijection 已足够。
4. 负例至少包括：删/改一个最坏方向原子权重、破坏一个 D4 像、缩短方向终点、增大 λ 使 containment 失败、open/closed event tie mutation。

只有 A 与 B 对 source worst 和全部五条件一致，且独立 checker 的边界负例通过，才有资格交给 T0 判断是否登记条件性结果；在此之前不更新 `4.59`。

## 6. 风险与停止条件

- 若 source 重放不能从锁定环境得到声明 worst，停止；不从 frontier 继承。
- 若 scaled `verify` 的 Condition 5 不与 source 一致，优先检查缩放映射/有理序列化，不调原子或 λ。
- 若独立 sweep 在事件边界与 source 分歧，保留首个反例，不用 epsilon/float 掩盖。
- 本方向只允许 fixed λ transfer，不做 λ 搜索、极限值、原子重优化或新站点检索。
- 即使全部通过，新增值也只是基于已有方法和已有证书的实例性 corollary；新颖性与外部优先权仍为 unknown。
