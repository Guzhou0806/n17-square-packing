# M19 非均匀并网：独立预审

日期：2026-09-17。结论：**可作为 M17 失败后的独立、确定性复用阶段立项；条件定理在数学上成立，覆盖前提仍待原来源 NumPy sweep 独立复演。** 本预审没有新增方向 sweep、网页检索或优化。

## 与 M17 的边界

M17 的冻结问题是：T019 的固定 1184 原子是否覆盖旧 181 节点的**全部 180 个中点**，从而形成 361 节点均匀网。生产运行在第 17 个实际计算行、旧区间 `k=14` 的中点发现

```text
t = 6006103/180000000,
minimum = 197153/200000,
threshold = 423327/425000,
minimum - threshold = -7003/680000 < 0.
```

因此 M17 的 361 节点候选失败并停止；它没有产生新下界。该失败行必须继续保存在 M17 的 `DIRECTIONS.jsonl` 第 17 行，不得从历史或汇总中删除。

在失败前，M17 精确计算并判为通过的 16 个中点对应旧区间

```text
K = {0,1,2,...,13,89,179}.
```

每一行的生产最小值均为 `200009/200000`，严格高于 `423327/425000`，余量为 `13537/3400000`。M19 的拟议输入是：旧 181 节点与这 **全部 16 个**已通过节点的并集，共 197 个节点；不加入失败的 `k=14` 中点，不计算其余 163 个未运行中点，也不在 16 个通过节点中再作选择。

这一区分必须如实表述：M19 不是“M17 全加密成功”，而是看到 M17 的部分结果后另立的**事后确定性复用推论**。事后形成不损害后续精确证书的数学有效性，但不能包装成 M17 预声明目标、独立发现或无数据依赖的网格设计。

## 197 节点网的精确最大隙

令

```text
h = 207107/90000000,
t_k = kh,  k=0,...,180.
```

旧网相邻区间 `k` 的半角隙正切为

```text
d_k = h/(1+k(k+1)h^2).
```

它随非负整数 `k` 严格递减。区间 `k=0,...,13` 已加入中点，所以每个子隙至多 `h/2`；额外细分的 `k=89,179` 也不可能控制最大值。最早未细分区间是 `k=14`，且 `d_14>h/2`。因此 197 节点网的最大隙不是估计，而是恰好

```text
D_197 = h/(1+14*15*h^2)
      = 621321000000/270300253166143
      = 0.00229863269724019928232335605930...
      < h.
```

枚举这 197 个固定有理节点的 196 个相邻隙给出同一结果，取到位置为旧节点 `t_14=1449749/45000000` 与 `t_15=207107/6000000`。该有限有理枚举只是本预审的代数核对，不是覆盖 sweep。

## 条件定理与潜在增量

若独立原来源 sweep 对上述 16 个新增方向逐一确认最小捕获质量严格大于 `423327/425000`，并与旧 181 节点的既有覆盖证据绑定，则全 197 节点的最小质量为生产记录所示的

```text
m = 200009/200000.
```

权重除以 `m` 后，总质量为

```text
(423327/25000)/m = 3386616/200009 < 17,
17 - 3386616/200009 = 13537/200009 > 0.
```

因此可原样复用 M14/T-022 的锐化包含和严格有理缩放族，得到条件下界

```text
s(17) >= (L/B)*sqrt(1+D_197^2)/(1+D_197)
      = 45900*sqrt(73062612901466039895961496449)
        /2702984545455608711
      = 4.5900426689726359505272262851896...
```

它比 M14 的 `4.5900309898665324511857440778448...` 高约
`0.0000116791061034993414822073448`。结论仍只是普通 `>=` 端点下界，不提供端点严格证书，也不证明 `s(17)>` 该值。

## 覆盖方法与历史重复判断

- **覆盖方法完全复用。** M19 不需要新 sweep 算法：方向仍由 `t=tan(theta/2)` 生成精确有理旋转；覆盖仍是对连续中心域的有限 event-cell 最小质量计算。生产的 M17 17 行来自锁定的标准库 segment-tree 独立实现。
- **独立复演已有合适实现。** 锁定上游来源的 `sqpack/fractional/sweep.py` 提供 NumPy 二维差分 `minimum_covered_mass_integer`，其 cell/span 构造与 M17 生产实现不同，适合对同一 17 行作交叉检查。它需要显式传入 `weight_scale(atoms)`。
- **推论方法也完全复用。** 把有限覆盖网的真实最大半角隙 `D` 代入 M14/T-022 缩放极限，只是同一定理对一个非均匀网的实例化，不是新通用方法。
- **当前保留历史中没有同一 N17 197 节点证书。** T019/M12/M14 使用旧 181 均匀节点；M17 是 361 均匀节点的失败尝试。本地报告、冻结输入和锁定上游 N17 case 中未见 `K={0,...,13,89,179}` 的 197 节点并网或相同 `D_197`。该判断限于现有保留历史；本轮按要求未作新 web 检索，不作外部优先权主张。

所以，M19 的**实例与已认证数值若通过独立复演将是新的**，但覆盖算法、质量归一化和缩放极限定理都不是新的。
