# M17/M18 来源、历史与定理预审

日期：2026-09-17。范围仅为阶段 A 预审；本文件没有运行方向 sweep、SLSQP、LP 或任何 packing 优化。

## 结论摘要

- **M17 可进入一次冻结的新增方向检查，但不能从既有 181 方向证书直接推出结果。** 锁定的 T019 证书只生成 `direction_steps=180` 的 181 个节点；本地保留物和锁定上游树中未发现 N17 的 361 节点证书、180 个中点方向结果或相应失败记录。既有 sweep 代码支持任意有理半角方向，因此可复用的是验证机制，不是新方向的覆盖事实。
- **M17 的几何增量成立的前提是新增覆盖。** 半角参数为 `t=tan(theta/2)`，即 `theta=2 atan(t)`。现有 `D=207107/90000000` 已经是相邻真实方向角差的一半之正切，不是误用了全角差；不能只改公式把它除二。若把旧网格与全部半步节点交错，才得到 361 节点并使新 `D` 恰为 `207107/180000000`。
- **M17 的充分质量门槛可比 1 稍弱。** 令 361 节点上所有可达 cell 的全局最小捕获质量为 `m`，固定原子总质量为 `M=423327/25000`。计数矛盾只需严格满足
  `17m>M`，即 `m>423327/425000≈0.9960635294117647`。
  因而 `m>=1` 是简单但非必要的充分条件；若某个新增方向低于 1，不应立即判失败，除非全局最小值不再严格超过上述门槛。等价地，可把所有权重除以精确的 `m`，恢复“每格至少 1、总质量小于 17”的标准证书形式。这只是原计数证明的归一化，不主张新方法。
- **M18 的精确实验组合没有在历史中执行过。** M13 从原 M8 Generic 做过全 17 角、`delta=1/1000` 的非光滑固定分支 SLSQP；Burns 只释放 4 角。M15 做过全 17 角、816 个光滑不等式和解析 Jacobian，但输入是 M3 与 **M13 修复后的 G17**，不是原 M8 Burns/Generic，而且仍是 `delta=1/1000`。因此“原 M8 两种子 + 全 17 角 + `delta=1/20` + 光滑 Jacobian”是两个新实例，但没有方法新意。

## M17：现有证据能证明什么

锁定输入 `workers/T1/outputs/m10_m11/global_followup/certificate.json` 的 SHA-256 为
`461cb731917bdaf7a58f54be651ca2c782bc519790d79d0fe4941c24fdd4c652`。其参数为：

- `L=459/100`，`B=9977/10000`，D4 对称；
- 1184 个非负权重原子，总质量 `423327/25000<17`；
- `angle_limit=207107/500000`、`direction_steps=180`；回放器据此生成
  `t_k=(angle_limit/180)k=k*207107/90000000`，`k=0,...,180`；
- 已验收的旧网格最小捕获质量为 `200009/200000`。

源验证器明确把方向解释为 `theta=2 atan(t)`，并把相邻网点 `t_1<t_2` 的半角隙正切定义为

```text
(t_2-t_1)/(1+t_1*t_2).
```

旧均匀 `t` 网格的首个间隔从 0 到 `h=207107/90000000`，分母为 1，故最大值恰为 `D=h`。这正是 M14 使用的量。

若且仅若加入

```text
t_(2k+1)=(k+1/2)h=(2k+1)*207107/180000000,
k=0,...,179,
```

并保留旧节点 `t_(2k)=kh`，则新网格为 `t_j=j*207107/180000000`，`j=0,...,360`。首个新间隔仍从 0 开始，故最大半角隙正切**恰为**

```text
D_361=207107/180000000,
```

不是近似值。其余间隔因分母大于 1 而更小。

但是，旧 181 个方向的覆盖结果不蕴含 180 个中点方向的覆盖结果。cell 事件集合和最小捕获质量会随方向改变；T019 JSON 只声明一个全旧网格最小值，也没有逐个中点结果。锁定 commit `035d84c655b4047bc9986c9a3db5106780d92f77` 的树中，N17 case 仅见三份既有 rung 证书、Burns control 和 replay；本地关键词及路径检查也未发现 N17 `direction_steps=360`、361 节点或半步结果。这个结论限于当前保留历史与锁定树，不等同于证明从未有人私下计算过。

## M17：可审查的条件定理

建议将 DIR014 写成下面的条件命题，并把 sweep 结果作为前提证书而非藏在推论中。

> 固定 T019 的 `L=459/100`、`B=9977/10000`、1184 个非负原子及其 D4 对称性和总质量 `M=423327/25000`。令方向网为 `t_j=j*207107/180000000`，`j=0,...,360`，并令 `m` 为这 361 个方向全部可达 event cell 的精确最小捕获质量。若独立精确 sweep 证明 `m>423327/425000`，则
>
> `s(17) >= 45900*sqrt(32400042893309449)/1797926306539`
>
> `= 4.5952970590877374981862415948379...`。

证明接口如下：

1. 旧 181 个偶数节点由 T019 已验收证据覆盖；新增的 180 个奇数节点必须逐方向精确检查。若生产实现选择统一重跑 361 节点，也应与旧结果逐项对照。
2. `m>M/17` 给出 `17m>M`；或将权重统一除以 `m`，此时每个 cell 捕获质量至少 1，而总质量 `M/m<17`。其余条件不变。
3. 新网格有 `D=D_361=207107/180000000`。沿用 M14/T-022 的锐化包含恒等式，对每个正有理 `q`，若
   `q^2 B^2(1+D)^2<1+D^2`，则边长 `qL` 被排除。
4. 取严格有理 `q` 的稠密族并向上嵌入，得到端点下界
   `L*sqrt(1+D^2)/(B(1+D))`，即上式。仍不声称端点本身存在一份严格包含证书，也不声称 `s(17)>` 该值。

该值比 M14 的 `4.590030989866532451185744...` 高约
`0.0052660692212050470004976`。增量来自**新 180 方向覆盖事实加上旧推论**，不是把旧 `D` 无条件减半，也不是新通用证明方法。

### M17 冻结与验收门槛

- 冻结 T019 原字节哈希、独立验收过的精确 sweep 源码哈希、奇数索引定义和输出 schema；不得改原子、权重、`B`、端点或事后挑选子网格。
- 每个新增方向保存精确 `t`、精确最小质量和达到最小值的中心/cell 见证；保存所有已运行行，包括首个失败反例。
- 预筛可按冻结顺序先做少量奇数索引，但“未过 1”不是终止条件；严格失败门槛应为 `m<=423327/425000`。等号也不够，因为计数矛盾要求严格大于。
- 全过后由独立实现复核 180 个新方向，重核全局 `m`、旧 181 行绑定、1184 原子、D4、非负性、总质量及新 `D`。若只复核汇总最小值，不能排除漏行或索引错位。
- 一个中点低于门槛只否定“这组固定原子、固定 B、固定 361 网”的候选，不否定其他加密网、重优化权重或更强 N17 下界。

## M18：历史去重与新问题边界

历史矩阵如下：

|阶段|种子|释放角数|角盒|约束/Jacobian|结果边界|
|---|---|---:|---:|---|---|
|M13 G17|原 M8 Generic|17|`±1/1000`|204 个含绝对值的固定分支约束；未提供解析 Jacobian|修复后约 4.6755325540，未过 M3|
|M13 B4|原 M8 Burns|4|`±1/1000`|同上|未改善 Burns|
|M15 M3|M3|17|`±1/1000`|816 个光滑不等式 + 解析 Jacobian|未改善|
|M15 G17|M13 修复后的 G17|17|`±1/1000`|816 个光滑不等式 + 解析 Jacobian|微量改善 M3，但仍高于 Bidwell `alpha`|

M15 的冻结输入清单明确把 G17 的来源写为
`baselines/verified/M13_Generic_direction_release/witness.json`，所以不能把 M15 记成“原 M8 Generic 已做过光滑全角搜索”。M8 报告则给出原始认证种子：Burns 约 `4.6776482949651368`，Generic 为 `4.676812769745167`。

因此 M18 的两个实例确有新问题内容：分别从原 M8 Burns 与原 M8 Generic 出发，固定各自 136 个 `owner/local/sigma` 分支，释放全部 17 个半角参数，在 `t_i(seed)±1/20` 内使用既有 816 光滑约束和解析 Jacobian，各恰一次 SLSQP。它是既有方法在更宽盒与不同起点上的实例，不应称算法创新、结构家族发现或 basin 证明。

相对 `alpha≈4.67553009360455095...`，Burns 和 Generic 的起始差约分别为 `0.00211820136` 与 `0.00128267614`；需要实质收缩，不能把 M15 的 `10^-15` 量级变化外推为成功概率。

### M18 风险与认证门槛

- `delta=1/20` 是 M13/M15 的 50 倍。半角参数盒并非角度弧度盒；`theta=2 atan(t)`，所以同一 `delta t` 在不同 `t` 上对应不同角变化，近 `t=0` 时全宽可接近 0.2 rad。报告必须继续使用 `t` 盒表述。
- 固定分支约束是完整非重叠的充分条件，但宽盒内最有利分离轴可能改变；因此失败可能只是冻结分支/局部 SLSQP 的失败，不是宽盒中不存在更优 packing。
- SLSQP 的 success、浮点目标低于 `alpha` 或单个固定分支余量均不构成几何证书。每个返回向量仍须按冻结规则仅做一次有理化和一次精确统一修复，再检查 68 个墙约束、136 对方块及每对 4 个候选轴的完整 Fraction SAT。
- 纪录分类必须比较**修复后的精确有理边长**与 M16 的代数根。M16 已有 `a<alpha<b`，其中
  `a=4.67553009360455095163411127048314`、
  `b=4.67553009360455095163411127048316`。
  若候选 `<a`，即可严格证明越过；若候选 `>b`，即可严格证明未越过；若落入 `[a,b]`，必须用既有 Sturm 流程细化根区间或直接做精确代数比较，不能用显示小数决定。
- 只改善各自种子、M3 或 M15 但仍高于 `alpha`，应登记为本地有理见证改善，不登记为公开最佳上界突破。两次均无改善也只是一组有限负结果。
