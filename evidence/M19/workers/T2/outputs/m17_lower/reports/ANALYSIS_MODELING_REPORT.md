# M17 下界路线阶段 A 建模报告

根据题目动态调整问题数量。

本任务共 1 个子问题：审查在 T-019 固定原子测度中插入 180 个奇数半步方向后，是否能把 M14 的方向支持误差从 `h` 降为 `h/2`，以及后续需要怎样的有限证书才能推出新下界。

本阶段不运行新方向 sweep，不产生新的已认证下界。

## 1. 总体建模框架

```text
冻结T-019与M12/M14证据
 -> 构造361点交错方向网
 -> 静态检查D4、终端、D=h/2、可行中心域
 -> 一般化质量计数门槛
 -> 定义180个新方向的完整覆盖证书
 -> 全部独立通过后复用M14严格缩放极限定理
```

### 输入与已知条件

- 容器边长 `L=459/100`。
- 探针边长 `B=9977/10000`。
- 原方向步长 `h=207107/90000000`，旧网 `t_k=k h`，`k=0,...,180`。
- T-019 原子 1184 个，非负权重，总质量
  `M=423327/25000<17`，关于容器 D4 对称。
- 旧 181 行已经独立验收，最小捕获质量
  `200009/200000>1`。
- M14 已证明方向误差上界为 `D` 时的锐化支持包含和严格有理缩放极限。

### 决策对象与评价指标

本阶段没有优化变量。待验证对象是新增奇数索引方向

```text
t_j = j*h/2,  j=1,3,...,359.
```

核心评价量是每个方向在完整可行中心域上的精确最小捕获质量
`m_j`，以及全网最小值 `m=min_j m_j`。

### 依赖关系

- 181 个偶数行通过 `t_(2k)=t_k` 精确继承旧证据。
- 新结论只缺 180 个奇数行的完整有限覆盖。
- 只有所有新行通过冻结的严格质量门槛，才能启用条件端点公式。

### 结果展示

本阶段使用精确数值表、证书字段和状态表，不生成图像。方向网和支持误差是一维精确关系；图形不能替代完整中心域覆盖证明。

## 2. 假设敏感性预检

### 模糊表述及解释

#### “质量至少 1”是否必要

解释 A：逐探针必须捕获至少 1，沿用旧证书陈述。

解释 B：只需逐探针最小质量 `m` 满足 `17m>M`。

解释 B 更一般且严格成立。17 个严格内含于互不相交单位方块内部的闭探针两两不交，故其捕获质量之和不超过总质量 `M`。若每个至少捕获 `m`，则总和至少 `17m`。只要 `17m>M` 即矛盾。

因此冻结门槛为

```text
tau = M/17 = 423327/425000 ≈ 0.9960635294,
```

并要求严格 `m>tau`。`m=tau` 不足以推出矛盾。

#### “半步”是参数差还是实际角差

新点是在有理半角参数 `t` 中取算术半步，而不是在实际角度中取算术平均。相邻实际方向的一半间距正切为

```text
(t_(j+1)-t_j)/(1+t_j*t_(j+1)).
```

因为参数差恒为 `h/2`、分母从 1 开始递增，最大值在首区间，恰为 `h/2`。所以本提案确实得到 `D=h/2`，不需要声称实际角度等距。

#### 新方向失败意味着什么

- 若某个新方向存在精确可行中心且捕获质量 `<=tau`，则否定这份固定 T-019 测度和统一最小值计数证书。
- 它不否定不同测度、不同探针边长、非均匀方向论证或其他下界方法。
- `tau<m<1` 不是失败，而是一般化门槛下的通过。
- 超时、程序错误或未完成分区都是未知，不是反例。

### 快速验算与递进性检查

静态检查得到：

| 项目 | 精确结果 | 结论 |
|---|---|---|
| 新网点数 | 361 | 正确 |
| 旧偶数行 | 181 | 与旧网逐项相同 |
| 新奇数行 | 180 | 尚未 sweep |

`GO_CONDITIONAL_180_ODD_ROWS_UNCHECKED`，而不是新下界通过。

## 4. 条件定理模型

### 4.1 方向覆盖、D4 与终端

单位正方形方向模 `pi/2`，再用反射化到 `[0,pi/4]`。有理方向参数满足 `theta=2 arctan t`。源终端

```text
T=207107/500000
```

满足 `T^2+2T-1>0`，即超过 `tan(pi/8)`，因此覆盖基本方向区间。

对相邻新网点，最近方向误差 `delta` 满足

```text
tan|delta| <= D
D = max_j (t_(j+1)-t_j)/(1+t_j*t_(j+1)) = h/2.
```

### 4.2 旧行继承

`t_(2k)=k h`。只要原子、`L`、`B`、闭边界规则和旧行文件的字节绑定不变，181 个偶数行无需重新 sweep，其最小值逐项继承。

任何测度、权重、探针边长、容器边长或捕获边界语义变化都会使继承失效。

### 4.3 新行覆盖目标

对每个奇数 `j`，需要精确求解

```text
m_j = min { captured_mass(c,t_j) : c belongs to the full feasible centre domain }.
```

捕获矩形闭、权重非负、可行中心域有内点。可复用 M12 的独立开胞元分区思想，但必须由独立实现重放全部 180 行，或验证同等完备的有限胞元证书。抽样中心、局部优化和单个最小见证都不足以证明全域下界。

### 4.4 一般化质量计数

若全网 `m>tau=M/17`，任何假设存在的 17 方块装填都产生 17 个两两不交探针。于是

```text
M >= mass(union of probes)
  = sum mass(probe_i)
  >= 17m
  > M,
```

矛盾。

### 4.5 支持包含与端点

对 `0<=w<=D<1`，M14 恒等式仍成立：

```text
(1+D)^2(1+w^2)-(1+w)^2(1+D^2)
  =2(D-w)(1-Dw)>=0.
```

因此所有满足

```text
q^2 B^2(1+D)^2 < 1+D^2
```

的正有理 `q` 给出严格内含探针。若 180 个新方向全部通过质量门槛，则稠密极限推出

```text
s(17) >= S
S = L*sqrt(1+D^2)/(B*(1+D))
  = 45900*sqrt(32400042893309449)/1797926306539
  ∈ [4.59529705908773749818, 4.59529705908773749819).
```

该值比 M14 端点约高 `0.0052660692212050470`。这只是条件收益，当前不能登记。

端点处支持包含取等，本路线只证明 `>=S`，不证明 `>S`，也不提供端点单一严格证书。

## 5. Pilot 与完整运行方案

### 5.1 固定 pilot

在任何运行前冻结四个奇数行：

| 新网索引 | `t` | 选择理由 |
|---:|---|---|
| 1 | `207107/180000000` | 首区间、最大角差位置 |
| 199 | `41214293/180000000` | 旧最小值在 99/100 转换处的中点 |
| 335 | `13876169/36000000` | 旧最小值在 167/168 转换处的中点 |
| 359 | `74351413/180000000` | 终端相邻中点 |

不得依据 pilot 结果替换方向或追加自适应方向后仍称“固定 pilot”。

### 5.2 停止与判定

- 任一行出现精确直接捕获质量 `<=tau` 的可行中心：保存反例并停止该固定证书路线；不宣称全局下界路线失败。
- 全部四行 `>tau`：pilot 通过，但 176 行仍未知。
- 超时、资源错误、分区不完整：标记 `INCONCLUSIVE`。
- 只有全部 180 个奇数行经过完整独立验收且严格 `>tau`，才进入端点正式证书。

## 6. 证书与独立验收接口

详细字段见 `M17_CERTIFICATE_SCHEMA.md`。最低独立验收包括：

1. 源证书、旧方向、M12/M14、协议、生产者、结果的完整哈希绑定；
2. 重新验证 1184 原子、聚合 D4、非负权重和总质量；
3. 精确生成 361 网并检查所有偶数行继承；
4. 对 180 个奇数行完整重算可行中心域，而非只读生产者最小值；
5. 直接复核每个最小见证；
6. 严格比较全局最小值与冻结门槛 `423327/425000`；
7. 独立验证 `D=h/2`、终端、支持恒等式、严格缩放族与端点根；
8. 区分精确反例、超时/错误和正式通过。

## 7. 风险与定理边界

- 原子覆盖函数不是可用简单连续性下界控制的光滑函数；旧方向通过不蕴含中点通过。
- 旧证书最小质量只比 1 高 `9/200000`，但一般化门槛提供约 `0.00398` 的额外余量；实际是否足够必须由 sweep 决定。
- 旧行继承依赖所有几何和捕获语义完全不变。
- 单个新方向 `<=tau` 只否定固定 T-019 测度的统一最小值证书。
- 全部方向通过也只给出下界，不证明最优性、世界纪录或方法新颖性。

## 8. 阶段 A 结论

条件定理成立：如果 180 个新增奇数半步方向的完整可行中心域最小质量全部严格高于 `423327/425000`，则 361 点网的支持误差可精确替换为 `D=h/2`，并推出

```text
s(17) >= 45900*sqrt(32400042893309449)/1797926306539
       ≈ 4.59529705908773749818.
```

静态审查未发现 D4、终端覆盖、旧行继承、方向有理性或可行中心域方面的明显不可能性质。唯一未决且不可绕过的条件，是 180 个新增方向的完整精确覆盖质量。

## 9. 阶段 A 之后的冻结运行结果

T0 后续冻结的实际协议采用旧区间索引 `0,89,179` 作为三个 pilot，
与本目录早期 `PILOT_PROPOSAL.json` 的设计建议不同；后者从未获授权或
执行，现仅保留为阶段 A 历史。

冻结运行三个 pilot 全部通过，随后按未使用旧区间升序继续。在第 17 个
已计算新方向、旧区间 14 的中点（新网索引 29）首次出现

```text
t = 6006103/180000000
mass = 197153/200000
mass - tau = -7003/680000 < 0.
```

独立审计没有重跑 sweep，而是验证该中心严格合法，并逐一检查 1184 个
原子；闭探针直接捕获 125 个原子，质量恰为上述值。因此 M17 固定 361
点全加密证书正式失败。该结论只针对固定 T-019 测度、`B`、全中点网和
统一最小值计数路线。

M17 在失败前留下 16 个报告通过的新方向。另立的 M19 确定性推论把这
16 点与旧 181 点合并为 197 点非均匀网，保持 M17 失败记录不变。静态
复算全部 196 个相邻间隙后，唯一最大值位于首个未分割旧区间
`[14h,15h]`：

```text
D19 = h/(1+14*15*h^2)
    = 621321000000/270300253166143
    < h.
```

若 T1 锁定的独立二维差分 sweep 对全部 17 个已观测方向逐行复演一致，
则 16 个保留方向可与旧证据共同推出条件端点

```text
S19 = 45900*sqrt(73062612901466039895961496449)
      /2702984545455608711
    ∈ [4.59004266897263595052, 4.59004266897263595053).
```

当前 M19 状态仍为 `GO_PENDING_T1_INDEPENDENT_17_ROW_FULL_REPLAY`。生产者
保存的最小中心只能证明该质量可达到，不能单独证明完整中心域下界。
